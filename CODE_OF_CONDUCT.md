# Code of conduct

This project is a technical collaboration. Participants are expected to be
respectful, precise, and constructive.

Acceptable behavior includes discussing evidence, questioning assumptions,
acknowledging uncertainty, and separating technical criticism from personal
criticism. Unacceptable behavior includes harassment, discriminatory language,
threats, publishing private information, deliberate disruption, or unsafe advice
presented as verified fact.

Maintainers may edit, hide, or remove content and restrict participation when this
policy is violated. Report conduct concerns privately through the repository's
security contact mechanism. Reports will be handled as confidentially as
practical.
